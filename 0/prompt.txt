   Each `*` recursively tries every remaining text position without memoizing `(textIndex, patIndex)`, so patterns containing repeated stars and literals have exponential rejection time.

   This is reachable during pathname expansion before a Bash tool runs: with one filename consisting of 40 `a` characters, parsing `echo` followed by an unquoted pattern of twelve `*a` segments and a final `b` exceeded a four-second bounded reproduction. Because this synchronous matcher runs inside the hook, the judge’s HTTP timeout cannot interrupt it, and slightly larger inputs can stall tool processing. Memoize match states or use a bounded matching algorithm.
